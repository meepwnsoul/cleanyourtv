# 气泡桌面 Bubble Home

给高配电视的视频壁纸桌面。打开 [`bubble-home.html`](bubble-home.html) 体验：方向键在气泡之间按位置就近移动，向下进入左下角的信号源、网络、设置，回车打开。

**视频不在仓库里。** 设计时用的那段视频来源不明，不能随仓库分发。请把一段你有权使用的 16:9 循环视频命名为 `swamp.mp4` 放在 HTML 旁边；也可以再放一张 `poster.jpg` 作为封面。没有视频时背景是黑色，界面照常可用。

## 交互

- 8 个应用气泡分两列错开排在右侧，各自轻轻上下漂浮，彩虹边缓慢流转，右侧不时有小气泡升起。
- 焦点气泡放大到约 1.75 倍，果冻般弹一下，彩虹边变亮并发光；离它近的气泡沿径向让开，不会遮住彼此的名字。焦点应用的名字以大字显示在气泡左侧，下面一行写"按确定键打开"。
- 按确定键时，气泡破成十几颗水珠飞散，0.5 秒后重新鼓起，然后打开应用。
- 左上角是大号细体时钟和中文日期，左下角是信号源、网络、设置三个按钮。
- `reduced_motion` 打开时，关掉漂浮、流转和破泡动画，视频照常播放。

## 实现进 launcher 时

- 视频用系统自带的播放器（`MediaPlayer` 加 `TextureView`）静音循环播放，不新增依赖。
- 视频作为主题文件推到电视上，不打进 APK；建议使用 1080p 或 720p 的 H.264 编码，控制码率。
- 桌面一离开前台（打开应用、切换信号源、熄屏）就立刻暂停并释放解码器，回来再继续；解码失败时退回静态壁纸。
- 只在 2GB 以上内存的电视上开启，作为默认关闭的开关，由主题打开。
- 气泡用位图加简单变换绘制，每帧不分配内存。
