# Turntable Home：交接说明

本文件写给接手的 agent（Codex、Claude Code 等）。任务是把定稿的「唱片机」桌面实现进 cleanyourtv 的 launcher。

- 仓库：https://github.com/Gathin23/cleanyourtv
- 动手前先读仓库里的 `AGENTS.md`、`CONTRIBUTING.md` 和 `themes/README.md`，三者的规则优先于本文件。

## 场景坐标

以下坐标都基于底图 1672×941，实现时按屏幕等比缩放。

- **唱片**
  - 中心 (440, 346)，横半径 296，纵半径 192（透视压扁比 0.6486）。
  - 底下压一层 6px 的暗色厚度和投影。
- **标签**
  - 半径 = 0.42 × 唱片半径。
  - 只有标签旋转，每秒 200°（33⅓ 转/分）。
  - 正确做法：先在圆形空间里旋转，再纵向压扁。
- **唱臂**
  - 抠图左上角放在 (540, 190)，支点 (758, 200)。
  - 落在唱片上时角度为 0°，抬起时 −27°（逆时针）。
  - 带 drop shadow (6, 9, 6px, 55% 黑)。
- **中轴**：放在 (428, 306)，尺寸 24×44，叠在标签上方。
- **唱片箱**
  - 封套区从 x=868 起，宽 776，底边 y=532。
  - 箱子前挡板是底图 (845, 497)–(1672, 647) 这块区域，必须画在封套上层，用来挡住封套底部。
- **VFD 显示屏**：矩形区域 (605, 692)–(1075, 822)。
- **旋钮**
  - 圆心分别为 (1215.5, 778.5)、(1373.5, 778.5)、(1532.5, 778.5)，半径 36。
  - 指示灯在 y≈719。

## 交互规格

以样机为准。

1. **焦点结构**：分两行，第 0 行是封套（应用），第 1 行是旋钮。
   - 左右键在行内移动。
   - 下键进入旋钮，上键回到上次选中的封套。
2. **封套**
   - 普通宽 84、高 296，相邻重叠 10px。
   - 焦点左边的封套 rotateY(+26°)，右边的 rotateY(−26°)，透视 900px，旋转轴在底边中点。
   - 焦点封套：
     - 尺寸 204×326，转正（0°），translateZ 70，上移 30。
     - 米白描边加暖色外发光，投影向左下。
     - 选中时一道斜向扫光扫过一次，约 1.1 秒。
   - 紧邻焦点的两张亮度降到 0.7。
3. **换唱片**：焦点改变时依次执行：
   1. 唱臂抬起，转速降到 0
   2. 约 0.38 秒后标签淡出，重画为新应用
   3. 标签淡入
   4. 唱臂落下
   5. 再过约 0.55 秒恢复转速
   - 连续快速切换时要取消前一次的定时器。
4. **OK 键（封套）**：打开应用。样机里唱片短暂加速到 3 倍转速。
5. **OK 键（旋钮）**：
   - 旋钮动作：先缩到 0.88，再转一格（INPUT 40°，其余 30°），带回弹。
   - 光圈向外扩一圈波纹，指示灯闪一下。
   - VFD 闪烁着显示对应信息，2.4 秒后回到时钟：
     - INPUT：依次显示 HDMI 1 / HDMI 2 / LIVE TV，真机上换成实际的信号源列表
     - WI-FI：显示网络名和信号格
     - SETTINGS：显示 SETUP，并打开设置
6. **VFD 时钟**：七段数码管，未点亮的段保持 7% 透明度的余辉。

## 落地约束（不可违反）

- **不做视频壁纸、不做模糊、不加后台服务**，目标是 1GB 内存的电视。
- **默认关闭。**
  - 新增一个开关键，例如 `turntable_home`，按 AGENTS.md 里「Add an off-by-default launcher switch」的步骤实现：
    - `config.xml` 加默认值
    - `Config.java` 读取该键
    - `themes/README.md` 补表格行
    - 各语言的 strings
  - 新建 `themes/turntable/config.json` 开启它。
- **图片放进主题文件夹推送到电视，不要打进 APK。** APK 有 480KB 的硬上限。
  - 底图要转成 JPEG，控制在约 300KB 以内。
  - 其余图层都很小。
- **动画写法**参考 `PetalShowerView.java`：
  - 每帧不分配内存。
  - 标签预先渲染成位图，每帧只做旋转。
  - 离开桌面（onPause）立即停止绘制。
  - `reduced_motion` 打开时全部静止。
- **封套颜色**从应用图标取主色，封套顺序沿用 `dock_apps`。
- **测试**：必须在真电视上截图，并从四个方向各按一次方向键测试。
- **PR**：提交上游之前先开 issue。没有用户同意，不要提 PR。
